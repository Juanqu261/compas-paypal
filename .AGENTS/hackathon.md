# Hackathon

COMPAS is an entry for the Interledger Open Payments Hackathon 2026. The official rules URL was not verified when this note was written.

The submission is a public GitHub repository. Eligibility needs a working proof of concept with a real Open Payments integration. Simulated wallet screens do not satisfy that requirement.

The demo must show a payment request, authorization, payment execution, and successful completion. The medication path should complete. The alcohol path must create no outgoing payment.

AI usage is disclosed in `AI_USAGE.md`. The exact coding prompts are stored in `prompts/`. The team must review and understand AI-generated work before submission.

`prompts/001-repository-foundation.md` is the historical single-app prompt. `prompts/002-monorepo-restructure.md` is the monorepo prompt. Do not rewrite earlier prompt logs.

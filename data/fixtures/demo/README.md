# Demo fixtures

These JSON files are `demo/test data`. They are not PayPal responses and not computed policy decisions.

- `medication-pharmacy.json` — Pedro's medication mandate and a pharmacy purchase. Story outcome: `ALLOW`.
- `alcohol-rejection.json` — the same mandate at an example liquor store. Story outcome: `DENY` / `PURPOSE_MISMATCH`.

Category claims are `SELF_DECLARED`. That is not verification.

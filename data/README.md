# Data

Data assets for COMPAS. This folder is not a database.

- `fixtures/demo/`: the demo stories, labeled `demo/test data`. The pharmacy purchase is `ALLOW`, the alcohol purchase `DENY`.
- `seeds/`: reference data the backend loads. See `seeds/README.md`.
- `migrations/`: the Postgres schema. See `migrations/README.md`.
- `schema/`: what each table holds and the rules Postgres enforces.
